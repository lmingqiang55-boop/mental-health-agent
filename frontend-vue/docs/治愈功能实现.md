### 2.1 后端新增（为治愈小工具提供数据）

  | 方法 | 路径 | 用途 |
  |------|------|------|
  | GET | `/api/heal/contents?mood=&tag=` | 治愈内容库（音景/呼吸/正念/小文章）+ 心情标签 |

## 三、开源方案候选（选型记录，已按此落地）

> 选型原则：优先 **纯 vanilla JS / 单个 `<script>` 可直接引入 / 无构建**，能直接塞进现在的静态前端；React 系方案标注改造成本。

> **落地说明（2026-10-09）**：本节是实施前的选型调研记录，10 个功能已按下表方案完成。实际采用的方案：
> - **#1 情绪云图** → wordcloud2.js（已 vendor 到 `assets/vendor/wordcloud2.js`）
> - **#2 呼吸 / #6 身体扫描** → 移植 `midorikocak/breathe` 的呼吸节律；#6 自绘 SVG 人体分区
> - **#3 睡眠音景 / #7 情绪推荐音景** → Web Audio API（`AudioContext`）实时合成播放 + 「情绪 → 音景」映射表，**未打包任何音频素材**
> - **#4 打卡** → 移植 `streakr-habit-tracker` 的打卡网格 + 连续天数逻辑
> - **#5 认知重构** → 移植 `cbt-toolkit` 的想法记录 / 认知扭曲判定思路（前端本地）
> - **#8 涂鸦** → 原生 Canvas 自绘（无第三方）
> - **#9 番茄钟** → 移植 `ikristina/pomodoro` 的 Web Audio 计时思路
> - **#12 成长回顾** → 自绘情绪星图 + wordcloud2.js 关键词云（未引 Cal-Heatmap，改自绘以保持一致）
