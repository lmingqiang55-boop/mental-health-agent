# 心晴 · 设计规范 v0.1

> 项目：过程可解释的抑郁症多模态测评治愈和管理一体化平台
> 网页名：心晴 ｜ AI 助手：小晴 ｜ 双端：学生端 + 管理端
> 视觉稿：style-preview.html（风格对比）、key-pages.html（关键页面）
> 状态：已确认，待「开始正式」后落地实现

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| 温暖不幼稚 | 治愈感来自留白、圆角、柔和光影，而非卡通元素 |
| 一次一件事 | 测评/治愈场景单屏聚焦，减少学生心理负担 |
| 过程可解释 | 所有结论必须附「为什么」依据，用证据卡呈现 |
| 双端分气质 | 学生端温暖陪伴，管理端白色专业克制 |
| 克制用红色 | 红色只给紧急求助与高危预警，不用作装饰 |

## 3. 字体与排版

- 字体族：系统黑体 `"PingFang SC","Microsoft YaHei","Helvetica Neue",Arial,sans-serif`，不加载外部字体
- 字阶（学生端）：问候大标题 20 / 页面标题 17 / 卡片标题 15 / 正文 14 / 辅助 12 / 标签 11
- 字阶（管理端）：页面标题 18 / 面板标题 14 / 正文 13 / 表格 12–13 / KPI 数值 28(700)
- 字重：标题 700，强调 600，正文 400；数字可用 700–800 增强仪表感
- 行高：正文 1.6，卡片辅助文字 1.5

## 5. 动效规范（适度氛围）

| 动效 | 参数 | 用途 |
|---|---|---|
| 呼吸光晕 | 5s ease-in-out 无限，scale 1→1.18 | 首页/治愈页顶部氛围 |
| 卡片入场 | rise：上移 10px + 淡入，.6s ease， stagger 80ms | 页面加载 |
| 麦克风涟漪 | 2s ease-out 双圈扩散 | 测评录音中 |
| 仪表盘 | 1.4s ease 描边生长 | 报告页得分环 |
| 因子条 | 1s scaleX 生长 | 报告页因子 |
| 过渡通用 | .2–.3s ease | hover/选中/换肤 |
| 降级 | `prefers-reduced-motion` 时全部关闭 | 无障碍 |

## 6. 核心组件

**学生端**
- 心情选择器：5 档圆形表情，选中 scale(1.12) + 实心主色
- 对话气泡：AI 白底暖边框（左小角）、学生主色渐变（右小角）；AI 气泡带头像+「小晴」
- 麦克风按钮：62px 主按钮 + 双层涟漪环；状态文案「正在聆听… 说完点这里结束」
- 摄像头小窗：右上 58×74 圆角浮窗，可关闭（关闭后仅语音，不影响有效性）
- 进度条：5px 胶囊渐变条 + 「第 x / 9 题」+ 暂停按钮（支持续测）
- 紧急求助：浅红底胶囊，固定于首页底部/各页可达
- 底部导航：首页 / 测评 / 治愈 / 我的，选中橙色
- 可解释证据卡：虚线分隔 + 「可解释依据」标题 + 引用原话 → 结论的高亮句式

**管理端**
- 布局：左纯白侧边栏（200px）+ 顶栏 + 内容区（#F6F8FB）
- KPI 卡：白底 1px 边框，数值 28px/800，趋势小字绿涨红降
- 预警列表：色点 + 学生（脱敏）+ 事由 + 分级徽章（高危/关注/已处置）
- 表格：13px，行高 44px，表头 #F8FAFC
- 角色化：系统管理员/心理教师/班主任/管理层共用框架，按角色换侧边栏菜单与默认看板

## 7. 文案语气（UX Writing）

- 小晴口吻：第二人称、短句、先共情后建议；例：「躺很久睡不着确实挺熬人的」
- 报告必带免责声明：「本结果仅作参考，不构成医学诊断」
- 预警相关：学生端不出现「已预警」「高危」字样；求助话术温和（12356 + 校内心理老师）
- 按钮文案动词化：「开始」「暂停」「继续说」

## 8. 无障碍与边界

- 正文对比度 ≥ 4.5:1；橙色文字用 #EA6A2E（深主色）而非 #FF8A5C
- 可点区域 ≥ 40px；测评/治愈主操作 ≥ 56px
- 空状态：插画位 + 一句共情文案 + 一个主行动按钮
- 数据脱敏：管理端列表默认姓名打码（张**），专业版按角色解锁
