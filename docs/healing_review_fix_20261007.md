| 问题 | 修复后行为 |
| --- | --- |
| 较低等级风险提前返回 | 先收集全部上下文中的风险，再选择最高等级。“现在完全无法上学，今晚准备跳楼”与反序输入都进入高风险求助；评估已有中风险、背景、对话和重要经历之间也不会互相遮蔽。 |
| 暂停或准备漏记反馈 | 纯暂停或纯准备继续允许无需模型处理；有明确效果或拒绝时，先完成原话与方法关联校验，再暂停。前轮已尝试、本轮只说无效或更难受也会记载并停用对应方法；另一方法的准备意愿独立保留且不重复记载。模型失败保留原状态，重试只提交一次。 |
