# 队友更新须知：拉了最新代码之后要自己补什么

这份写给队友看，三分钟能做完。对应这一批提交（多模态一致性打分、语音真探测、
逐帧落盘开关、治愈工具箱按心情筛选这几件事）。

**结论先说：没有新的模型包要互传，但有两个 Python 包变了，另外有一个人脸权重文件
不在仓库里、需要每台机器各自下一次。**

---

## 一、必须做：重装一次 Python 依赖

这次有两处依赖变化，不重装就会有功能静默失效：

| 包 | 这次的变化 | 不补会怎样 |
| --- | --- | --- |
| `cnsenti` | **新增**（0.0.7） | 中文情绪词典那一路直接没有，只剩两张手写口语词表：很多句子读成"看不出方向"，评估报告里"文字和表情是否一致"基本不会触发。**不报错，只是悄悄变弱。** |
| `edge-tts` | **7.2.8 升到 7.3.1** | 网页朗读语音会稳定返回 403。这不是网络问题、也不是密钥问题，就是版本问题（7.2.8 及更早的合成握手会被拒）。 |

> 顺带更正一句早期提交说明里的说法：「cnsenti 缺失时降级为规则集，不影响主链路」——
> 这句不准确。真实情况是缺它的时候**词典那一路直接没有**，只剩手写口语词表兜着，
> 不报错但明显变弱。这也是把"拉取后重装依赖"写成必做项的原因。

在仓库根目录、激活项目环境后执行：

```powershell
conda activate mental-health-agent
python -m pip install -r requirements.txt
```

用 conda 一处更新也行（它会读同一个 `requirements.txt`）：

```powershell
conda env update -f environment.yml --prune
```

要联网。装完这样确认（两个都能打印版本就对了）：

```powershell
python -m pip show cnsenti edge-tts
python -c "from cnsenti import Sentiment; print('cnsenti ok')"
```

> 只想跑对话、不看摄像头、不用网页朗读的队友，这一步也建议做：
> `cnsenti` 缺失会让评估报告里的多模态那一段变空，容易被当成 bug 查半天。

## 二、必须每台机器各做一次：下载人脸权重（约 227 KB）

人脸检测换成了 YuNet，权重文件 `face_detection_yunet_2023mar.onnx` **不进仓库**
（`.gitignore` 里排除了 `backend/vision/weights/`）。执行下面这一句即可，脚本会
自动下载并按 SHA-256 校验：

```powershell
conda activate mental-health-agent
python -m backend.vision.face_weights
```

看到 `YuNet 权重就绪：<路径>` 就成了。重复执行是安全的（已存在且校验通过就直接返回）。

要传给队友的话，传这两个值就够对方自查：

- 文件名：`face_detection_yunet_2023mar.onnx`
- 大小 232589 字节，SHA-256 `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4`

也可以把你自己下好的这个文件直接发给队友，让他放到
`backend\vision\weights\`（目录不存在就新建），文件名别改。或者放到任意位置，
再用 `.env` 里的 `VISION_YUNET_MODEL=` 指过去。

**下不下来也不影响启动**：拿不到权重时后端会自动退回老的 Haar 级联，只是暗光、
侧脸、小脸会漏检更多（实测暗光漏检约多四成）。这是画质问题，不是崩溃问题。

## 三、`.env` 要不要动：可以不动

队友本地已有的 `.env` 不补新键也能跑，新键都有代码默认值。只有下面三件事想改才需要动：

1. 想做阈值重校、要采集逐帧数据：把 `VISION_FRAME_DUMP_DIR` 设成一个目录
   （**建议放在仓库之外**，例如仓库同级的 `../vision_dump`）；不设就是关闭，不写盘。
2. 本机没有 `DASHSCOPE_API_KEY`、但不想看到语音状态是降级：把 `TTS_PROVIDER=edge`
   写进 `.env`。默认值是 `cosyvoice`，没有密钥时会自动退到 edge，但
   `GET /api/tts/status` 会一直显示降级。
3. 想调视觉/一致性的门槛：`.env.example` 里已经列全了（`VISION_ACK_*`、
   `CONSISTENCY_*`），含义见 `backend/core/vision_thresholds.py` 的模块说明。

改完 `.env` 要重启后端才生效。

- **前端**：这次后端没改接口字段的语义；前端自己的改动看前端同学那份交接文档。

## 六、还是不对时，先看这几条

- **朗读没声音 / 403**：先确认 `edge-tts` 是不是 7.3.1（7.2.8 一定 403），
  再用 `POST /api/tts/probe` 做真合成自检——"声音列表"能拉到不算数，它一直返回 200。
- **报告里多模态那段是空的**：先确认开过摄像头、并且有 2 句以上能读出情绪的对话；
  没有可比句子时给的就是 `null`（"暂不评估"），不是错误。
- **人脸老是检不出来**：先跑一遍权重下载；下载失败时后端用的是 Haar 兜底，暗光下本来就容易漏。
- **改动生效不了**：Python 代码改动需要重启后端；`.env` 改动也需要重启。
