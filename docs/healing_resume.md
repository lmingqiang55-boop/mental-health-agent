# 陪伴会话恢复

陪伴入口在内存会话失效后，从 `data/conversations.sqlite3` 恢复会话快照。
陪伴报告、消息、反馈、轮次、安全结论和幂等回执在每次成功发布时保存；
内存缓存仍保留两小时 TTL 和数量上限，缓存淘汰不再删除持久记录。
后端重启后，首次进入陪伴会重新加载保存的状态，不要求重复筛查。

升级前只有测评记录、没有会话快照的情况，会使用原 session_id 和匿名身份
重新建立陪伴，并由现有 Safety Agent 检查保存的报告。此前已经随内存丢失的
陪伴消息无法复原。安全暂停、中止以及服务不可用仍按现有边界处理。

普通筛查接口仍执行原有会话 TTL；显式恢复仅在陪伴入口进行。
隐私删除涵盖内存和持久快照，显式删除会话后不能从旧测评自动复活。
需要备份时同时保存此文件和测评数据库；包含敏感对话，应限制本机文件访问。

验证：`python -m pytest tests/test_session.py tests/test_healing.py
tests/test_healing_review_regressions.py tests/test_healing_resume.py -q`。
恢复用例覆盖重启、闲置超时、继续发送、重复提交、安全停止、旧测评迁移及删除。
