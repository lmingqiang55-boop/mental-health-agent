# 知识卡 `item_03`：睡眠变化

**归属**：C 项目对话式抑郁测评；条目 ID 与原型题面见 [`bank.py`](../../backend/assessment/bank.py)，状态、四档回答和完成条件见 [测评契约](../assessment_contract.md)。

**版本**：`card_item_03_v1_review`；资料与模拟案例已核对，尚未接入模型，未经临床审校或真实学生语料验证。
**用途**：给决策模型提示尚缺的条目含义、时间与频率信息；给问句生成模型提供已选动作的措辞素材。卡片不规定条目顺序，不决定分值，也不改变现有五种 `intent`。

## 1. 来源及适用边界

| 来源 | 本卡使用的事实 | 边界 |
| --- | --- | --- |
| [NIMH：PHQ-9 modified for Adolescents（PHQ-A）](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials/asq-tool/phq-9-modified-for-adolescents-phq-a) | 官方页面列出**过去两周**、四档回答；第 3 项为入睡困难、维持睡眠困难或睡得过多。 | 这是 C 项目条目范围和时间窗的首要来源；页面提供英文原文，不等于已经确定可正式施测的中文译文。 |
| [NHLBI：What Is Insomnia?](https://www.nhlbi.nih.gov/health/insomnia) | 解释失眠时会问：有合适的时间和环境，仍难以入睡或维持睡眠吗？ | 仅用作理解“没去睡”和“想睡却睡不着”的提问参考。失眠定义和慢性失眠诊断尺度**不是** PHQ-A 第 3 项的排除规则或计分门槛。 |
| [Chen 等，2024：中文 PHQ-A 心理测量研究](https://link.springer.com/article/10.1186/s12888-024-05783-3) | 248 名 12～18 岁、已确诊 MDD 的临床样本中，第 3 项 CFA 载荷为 0.47，较其他项低。 | 这是心理测量结果；不能据此推断学生一定难理解睡眠题、必须多问一句，或调整本项权重。论文的缓解截点也不能用于普通学生筛查。 |

## 2. 条目含义与缺失信息

NIMH 第 3 项覆盖三类经历：**入睡困难、睡着后难以维持睡眠、睡得过多**。系统仍按契约询问过去两周，并让学生在原有四档中确认。学生提到“睡不好”，只能视为线索；还需知道他说的是哪一种经历。“早醒后难再睡”可作为维持睡眠困难的具体描述，但不要把它写成新增的独立计分项。

“刷手机到凌晨”“赶作业没去睡”“周末补觉”“睡得晚但躺下很快睡着”都**不足以单独判断**第 3 项为阳性或 0 分。可以问躺下后是否难以入睡、夜里是否醒来难再睡，以及有没有睡得过多。主动晚睡与这些经历可能同时存在；不要仅凭前者排除后者，也不要用后者反推前者。

决策时分别检查三种缺口：

1. **含义**：原话说的是哪一种睡眠经历？“睡不够”是时间不够、睡不着，还是睡得比平时多仍觉得困？
2. **时间**：所述经历是否发生在过去两周？“去年”“最近两个月”不能自动替代本轮时间窗。
3. **频率**：学生是否已明确选定“完全没有／有几天／超过一半的天数／几乎每天”？“经常”“十天左右”只能形成候选，不能由系统直接定档。

白天困、成绩下降或注意力差可提示继续问睡眠经历，不能单独证明第 3 项。来自家长的话也不能替代学生本人对条目经历和频率的确认。

## 3. 与当前动作契约的对应

决策模型选择 `target_item_id` 和 `intent`；生成模型仅表达已选动作。以下是语义上合适的用法，**不是固定流程**。

| `intent` | 语义上适用的状态 |
| --- | --- |
| `open_topic` | `item_03.asked_once=false`；即使学生主动谈过睡眠，也还没有明确问过第 3 项。 |
| `clarify_period` | 已问过本项，但学生说的是过去事件或时间窗仍不清。 |
| `clarify_frequency` | 已问过本项，条目含义和过去两周时间窗清楚，但频率还未由学生在四档中确认。 |
| `resolve_conflict` | 本项有已记录的矛盾，须引用真实的学生原话。 |
| `confirm_mention` | 本项留有学生本人主动提及的证据，须引用真实原话；不能把家长描述直接当作学生经历。 |

**程序校验的实际范围**：当前 `validate_question_action` 校验条目是否开放、引用是否逐字可溯源、`open_topic` 是否未问过、`resolve_conflict` 是否有冲突，以及若干 `intent` 的基本前提。对 `clarify_period` 和 `clarify_frequency`，代码只要求本项已问过**或**已有证据，尚未检查“时间确实不清”或“频率确实不清”。因此“程序接受”不等于“语义合适”；不能在卡片中声称程序已验证这些缺口。

**动作空间待验证缺口**：若学生说“过去两周几乎每天睡不好”，时间和四档频率都清楚，却仍不知“睡不好”指什么，现有 `clarify_period`、`clarify_frequency` 都指错缺口。`confirm_mention` 也只表示确认主动提及，不能准确表达“澄清含义”。本卡把它记录为待验证的通用 `clarify_meaning` 候选（兴趣项“只是不喜欢数学课”也可能需要）；**此版不新增动作或改代码**。是否扩展契约，应先用同状态的模拟案例检查决策与问句。

## 4. 问句生成素材

这些是**单轮可选的表达方向**，生成器只在决策器选中 `item_03` 后使用，仍须遵守一句话、一个问号、限定过去两周的现有要求。

| 缺口 | 可参考的单问句 |
| --- | --- |
| 含义：主动晚睡与入睡困难 | “过去两周，你说的睡得晚，是躺下后睡不着，还是那时还没有去睡？” |
| 含义：维持睡眠 | “过去两周，你夜里醒来后会难以再睡着吗？” |
| 含义：睡得过多 | “过去两周，你有没有比平时睡得明显更多的日子？” |
| 时间 | “你说的这种情况，在过去两周里也出现过吗？” |
| 频率 | “过去两周，这种情况更符合哪一档：完全没有／有几天／超过一半的天数／几乎每天？” |
| 矛盾 | “以过去两周为准，你现在确认哪一次描述更符合实际？” |

第一行涉及两个可能含义，适合澄清具体经历；它**不**意味着现有代码已具备准确对应的 `intent`。学生报告天数时仍要请其自行选档。提问不要把“失眠”当作预设诊断，也不要加入 NHLBI 慢性失眠的时长或每周次数门槛。

## 5. 团队编写的模拟案例：核查动作空间

以下回答**不是学生真实语料**。表中状态均是假设本轮证据抽取、应用完成后、决策发生前的 `item_03` 状态；其他八项保持开放，`safety_flag=no_signal`。除注明外，`conflict=false`、`confirmed_by_user=false`、`score=null`；“证据”表示 `evidence_history` 中已保存学生本人逐字原话。表中的“可选动作”只讨论 `item_03`，最终选哪一项仍由决策模型决定。模拟状态不代表当前抽取器一定会自动生成该状态。

| 案例与学生本轮原话 | 本项决策前状态 | 已知事实；仍缺什么 | `item_03` 可选动作与边界 |
| --- | --- | --- | --- |
| **S1** “这两个星期好几晚刷手机到快一点才睡，躺下倒是很快睡着了。” | `asked_once=false`；`status=mentioned`；有本轮证据；无旧确认。 | 两周内主动晚睡、躺下很快入睡；尚不知夜里是否难再睡或睡得过多。刷手机的频率不是症状频率。 | `open_topic` 可明确问本项。不能用 `clarify_frequency` 追问刷手机的频率，也不能直接判 0。 |
| **S2** “这两周大概有十天，躺下后要一个多小时才睡着。” | `asked_once=true`；`status=needs_clarification`；有本轮证据；无旧确认。 | 时间、入睡困难含义清楚；尚未在四档中确认。 | `clarify_frequency` 合适；不能自行把十天换算为分值。 |
| **S3** “最近我躺下以后常常睡不着。” | `asked_once=true`；`status=needs_clarification`；有本轮证据；无旧确认。 | 入睡困难含义清楚；“最近”与“常常”都不足以确认时间窗和四档。 | `clarify_period` 可先核对时间；之后仍需四档确认。 |
| **S4** “过去两周几乎每天睡不好。” | `asked_once=true`；`status=needs_clarification`；有本轮证据；无旧确认。 | 时间和四档频率已明确；“睡不好”可能指多种情况，条目含义未知。 | 现有五类无准确的“澄清含义”动作；程序可能接受 `clarify_frequency`，但那会重复已知频率。此例用于检验 `clarify_meaning` 是否必要。 |
| **S5** “我睡得晚，周末就补觉。” | `asked_once=true`；`status=needs_clarification`；有本轮证据；无旧确认。 | 晚睡和补觉已知；是否存在入睡／维持困难或睡得过多、两周窗及症状频率均不清。 | 现有 `clarify_period` 可核对时间，但不能单靠这个 intent 表达含义澄清；不得由“补觉”直接判阳或判 0。 |
| **S6** “去年备考时天天睡不着，现在不确定。” | `asked_once=true`；`status=needs_clarification`；有本轮证据，`period=other`；无旧确认。 | 去年经历清楚；过去两周情况未知。 | `clarify_period` 合适；去年频率不得计入本轮。 |
| **S7** “我妈说我晚上睡得太晚。” | `asked_once=false`；`status=unasked`；本项没有可接受的本人症状证据；无旧确认。 | 只有转述，学生本人的睡眠经历未知。 | `open_topic` 可问本人；`confirm_mention` 缺少本项本人证据，不能把家长判断当作确认。 |
| **S8** “之前说没问题，其实这两周几乎每天躺下后都睡不着。” | `asked_once=true`；`status=needs_clarification`；`conflict=true`；证据历史保留前次“没有睡眠问题”和本轮原话；旧确认已撤回。 | 两次回答冲突，最终频率待本人确认。 | `resolve_conflict` 合适，`anchor_quote` 必须取保存的学生原话。 |
| **S9** “这两周超过一半的天数我都睡不够。” | `asked_once=true`；`status=needs_clarification`；有本轮证据；无旧确认。 | 时间与四档频率清楚；“睡不够”可能是睡眠机会少、入睡困难、维持困难或另有含义。 | 同 S4：当前缺少准确的含义澄清动作；不能为凑动作把它写成频率问题。 |

**自检结果**：S1、S2、S3、S6、S7、S8 可在现有动作词表中表达主要下一步；S4、S9 的含义缺口无法准确表达，S5 只能先问时间而不能完整表达含义澄清。这支持在下一步讨论通用 `clarify_meaning`，但尚不证明增加它能改善真实模型表现。
