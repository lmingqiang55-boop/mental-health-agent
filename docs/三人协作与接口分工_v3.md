# 三人协作与接口分工（当前实现：2026-10-03）

文件名保留以兼容既有链接。原先“自动语音切分”“turn_id/start_time/valence_avg”等示例已过时；本期按住/松开录音。当前字段以 [API 数据协议](api_spec.md) 为准，完整行为见 [摄像头与录音对接](vision_alignment.md)。

## A：对话决策与最终评估

- 读取完整文字对话，调用本机策略模型获得动作并生成基础回复；策略模型当前只消费文字。
- 规则式风险识别可读取本句视觉，危机提示优先；模型失败不保存半轮消息。
- 用户显式结束后，接收原文、逐句视觉快照及会话汇总，生成五维画像、关注指数和报告。
- 保留已绑定消息的语音与视觉信息；完成外部模型配置和真实响应验收。

## B：语音和摄像头分析

- 完整录音经 PyAV 解码/重采样，再由 SenseVoice 输出原文；不改写、不拆回合。
- EmotiEffLib 提供单帧情绪与 VA；不支持的指标保持 null。
- 按共同 capture_id 和毫秒区间聚合有效帧，冻结本句快照；聊天重试复用原结果。
- 后端从已绑定句级快照构造会话汇总；sample_count 计句级样本数。
- 继续验收真人短回答、否定词、句尾、光照、角度与缺脸情况。

## C：界面与浏览器设备编排

- 页面控制实际录音开始/停止，等待末次 dataavailable；权限等待不计入时间。
- 记录帧采集时间，完成摄像头生命周期与代次，最多一个帧请求在途。
- 汇合 ASR 与冻结视觉后提交一次聊天；展示原文、回复和结果。
- 取消、离页或新会话使旧请求失效；失败提供重试，保持 utterance_id、录音区间与视觉快照。
- 处理中阻止新输入/评估。聊天已发送后不宣称可以撤回；发送状态不明时重试确认或重新开始。

## 共同接口

| 内容 | 字段与位置 |
| --- | --- |
| 会话 | 所有请求 session_id |
| 发言唯一标识 | utterance_id，由前端生成，重试复用；turn_count 由聊天成功后递增 |
| 共同采集时间轴 | capture_id + performance.now() 毫秒值 |
| 单帧 | frame_id、capture_id、captured_at_ms，提交 /api/vision/frame |
| 录音 | speech.recording_start_ms / recording_end_ms，由 ASR 回显后提交聊天 |
| 本句视觉 | /api/vision/segment → vision_snapshot → 同一次 /api/chat |
| 会话汇总 | /api/assessment 默认从消息快照生成，也支持外部 evaluation_input.vision_summary |
| 回复 | reply、next_strategy、current_stage、risk、turn_count |
| 结果 | result.report、psychological_profile、concern_index、overall_level、risk |

录音区间不是 VAD 发音边界。UTC timestamp 不能与前端毫秒值相减。没有帧为 null；有帧无脸为 face_detected=false；缺测不填 0。原始画面和录音不持久化。
