# 自适应提问智能体：对话记忆与任务交接

更新时间：2026-09-30。本文供接手当前聊天智能体任务的人快速恢复上下文；以 C 盘项目的实际代码和测评契约为准。**本文不含 API 密钥。**

## 1. 当前目标与用户已确定的选择

- 这是人工智能算法比赛的**可控演示原型**。团队当前负责聊天部分的智能体；网页端由另一位队员负责。不要把长期部署、完整产品工程当作这阶段的主线。
- 面向中小学生的设想是：用自然对话覆盖九个抑郁相关主题，依据学生本轮回答和已记录状态**个性化选择下一问**，避免写死对话；不是减少题数。九项必须明确问过并确认，才能得到完整的九项映射结果。
- 用户明确要求**决策模型与问句生成模型分开**。决策模型选择 `target_item_id` 和 `intent`，生成模型只把已定动作写成适合学生的问句。LangGraph 负责组织节点与状态；模型负责选择下一步，程序校验动作是否合法。
- 知识库的用途是给模型提供条目含义、容易混淆的说法、缺失信息与措辞参考，不是把九项写成固定提问树。九项规模下可先使用按条目索引的结构化知识卡，无须先建向量数据库。
- 用户希望**一步一步推进**：先弄清技术和资料、做一个睡眠条目试点并验证是否改善下一问，再扩展。之前讨论过 RavenClaw、上下文老虎机、无训练数据时的策略和未来训练模型的位置；这些是思路讨论，**不是当前 C 项目已实现的算法**。
- 将来若拿到抑郁症对话数据，可用于改进证据抽取、动作决策或问句表达；目前没有相应训练数据，也没有训练好的专用决策模型。不要在比赛材料中写成已训练完成。

## 3. C 项目当前实现（2026-09-30 核查）

1. [测评契约](assessment_contract.md)以 [NIMH 发布的 PHQ-A](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials/asq-tool/phq-9-modified-for-adolescents-phq-a)前九项为基线：**过去两周**、四档频率、`item_01`…`item_09`。合同暂定对象为能独立理解问题的 **12～18 岁**中文使用者。九项全部明确问过并确认后才计算 `mapped_total`；主动提及但没明确问过的主题不算完成，未问项不补零。
2. [条目定义](../backend/assessment/bank.py)给出九项稳定 ID、标签和原型题面。C 的 `item_01` 是心境／易怒、`item_02` 是兴趣；`item_04` 是食欲、`item_05` 是疲倦。D 项目对应的数字顺序相反，映射须按**含义**。
3. ## 4. 已核对的资料结论

- [NIMH PHQ-A 页面](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials/asq-tool/phq-9-modified-for-adolescents-phq-a)可直接打开，明确给出**过去两周**、九个症状条目、四档回答及条目顺序；另列过去一年心境问题和功能影响问题。D 档案“未收录该页”不等于官方原件不存在。
- [APA 的《Severity Measure for Depression—Child Age 11–17》](https://www.psychiatry.org/File%20Library/Psychiatrists/Practice/DSM/APA_DSM5_Severity-Measure-For-Depression-Child-Age-11-to-17.pdf)明确写着 **adapted from PHQ-A**，它采用**过去 7 天**。不能据此把 C 项目的两周窗改为七天，也不能照搬其未答题比例估算规则。
- C 项目的条目顺序与上述 NIMH 版本相符。D 项目主要基于 PHQ-9：兴趣与心境（1/2）、疲倦与食欲（4/5）的编号和 C 项目相反。D 的 IRT 参数若以后需要使用，必须先按条目含义重映射；目前 C 的自适应提问不依赖这些参数。
- [NHLBI 失眠说明](https://www.nhlbi.nih.gov/health/insomnia)可帮助提出“没去睡，还是有机会睡却睡不着”的澄清问题。它是失眠定义，**不是 PHQ-A 睡眠项的新计分门槛**。不能仅凭“刷手机到很晚”“周末补觉”直接判定条目为 0 或阳性。
- [Chen 等 2024 中文 PHQ-A 研究](https://link.springer.com/article/10.1186/s12888-024-05783-3)纳入 12～18 岁已确诊 MDD 的临床样本；睡眠项载荷较低。这是心理测量发现，**不能推出学生必然难理解睡眠题、必须多问一句或调整权重**；论文给出的缓解截点也不能搬来给普通学生筛查。
- 当前 C 契约的 12～18 岁范围与用户早期提出的“中小学生”总体目标尚未完全对齐。现有资料不能支持声称 6～9 岁提问方案已验证。比赛演示可先按当前契约推进，若要覆盖小学阶段，需要单独明确年龄段与措辞方案。

## 5. 睡眠知识卡草稿：已发现的问题

当前文件是 [item_03.md](knowledge_cards/item_03.md)，版本 `card_item_03_v0_draft`。其优点是区分了决策模型所需信息与生成模型的措辞素材，也把模拟学生回答标为团队编写。接入前需修以下问题：

> **状态更新（2026-09-30）**：① **NIMH 官方页已直接取回**（HTTP 200），条目 3 原文与"过去两周"、四档选项均可逐字引用，见[材料对齐表补记](materials_alignment.md) §4 第 1 条。② 本节六项**仍按原样待处理**：另有一版 `card_item_03_v1_review` 出现在工作区（非本节所列逐项修订，来源未核对），不要据此认为六项已关闭。③ **睡眠卡的路线本身正在重新评估**：D4 数据集（医生—来访者中文对话，含医生 `action` 领域标签与对话级 `drisk`/`srisk`）可能使 §4／§5／§6 改由数据统计与验证得出，而不是继续手写。结论未定前不要扩写本卡。

1. 把“NIMH 页面未取到”改为已核对的官方直链，并以 NIMH 两周版为首要条目来源。
2. 把“明确不属于范围：主动晚睡／周末补觉”等绝对归类改成“单凭这些描述不足以判断”；澄清躺下后的情况及是否有睡得过多。不要从 NHLBI 的失眠定义推导 PHQ-A 自动排除规则。
3. 删除“低因子载荷 ⇒ 可能承载较高歧义／应更谨慎澄清”的因果推断；载荷只作背景。
4. 模拟案例 S1 只有主动晚睡，却建议 `clarify_frequency`，可能在追问无关行为的频率。S2 等案例同样缺少 `asked_once`、已有证据及确认状态；没有会话状态就不能列合法 intent 集合。每个案例应加状态，并区分“已知事实”“缺失信息”“模型可选动作”。
5. **真正的动作空间缺口**：学生说“睡不好”，时间和频率可能已清楚，但症状含义仍不清楚。现有五个 intent 没有准确表示“澄清含义”。知识卡把这种情况硬塞进 `clarify_period` 或 `clarify_frequency` 会造成语义错位。可设计通用 `clarify_meaning`（不仅用于睡眠，兴趣项“只是不喜欢数学课”等也适用），但应先在模拟案例中验证需求，再决定是否扩展动作契约和代码。
6. 当前代码对 `clarify_period`／`clarify_frequency` 主要检查条目是否已经问过或有证据，**未从状态中实际验证时间／频率是否模糊**。文档中“程序校验 intent 与状态相符”比现有实现更强。若加入知识驱动的澄清动作，须同步明确哪些是模型判断，哪些可由程序检查。
