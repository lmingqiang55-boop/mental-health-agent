- DAIC 的访谈是**半结构化**的：先建立 rapport 的中性问题 → 再问抑郁/PTSD 症状相关问题 → cool-down 结束。这与 PHQ-9 的固定条目顺序不同——这正是"对话式筛查"的天然形态。

**基线结论（已证实）：**
- 纯文本单模态在 DAIC-WOZ 抑郁二分类上的"可信"F1 区间大致 **0.76–0.84**（仅患者回答、不利用采访者 prompt）。

- **对标建议**：本项目若做"大学生自适应对话"，合理的文本单模态基线目标应设在 **F1 ≈ 0.78–0.84**；若报告 >0.90 必须做 Burdisso 式消融以排除 shortcut。

### A.3 对话行为/语言标记与抑郁的关联（已被心理学与计算研究证实）

以下均来自 Gratch et al. (2014, LREC) 综述的 DAIC 子研究及 Scherer/DeVault/Yu 等人的工作：

| 行为/语言标记 | 与抑郁的方向关系 | 证据强度 | 来源 |
|---|---|---|---|
| **言语启动延迟（time to onset）** | distress 个体**更慢开口**；每用户话轮首段启动时间的 SD 是抑郁最佳独特预测因子 | 已证实（DAIC-WoZ） | DeVault et al., 2013；Gratch et al., 2014 |
| **填充性停顿（filled pauses, "um/uh"）** | distress 个体使用**更少**填充停顿（注意：与直觉相反）；但 face-to-face vs WoZ 对比发现，对着虚拟人 Ellie 说话时填充停顿是面对真人的 2 倍 | 已证实（DAIC） | DeVault et al., 2013；Gratch et al., 2014 |
| **嗓音紧张度（tense vs breathy voice）** | 抑郁/PTSD 者嗓音更紧张；紧张嗓音区分抑郁 vs 非抑郁 **Acc = 75%**，区分 PTSD **Acc = 72%** | 已证实 | Scherer et al., 2013/2014 |
| **凝视角度** | distress 者凝视角度更向下；微笑强度更低、平均微笑时长更短；自我触摸/烦躁动作更多 | 已证实（face-to-face） | Scherer et al., 2013b；Stratou et al., 2013 |
| **话轮长度 vs 问题类型的交互** | 亲密问题的"启动延迟"预测 distress；rapport 建立阶段问题的"说话长度"更预测 distress——即行为标记的预测力随问题类型调节 | 已证实（DAIC） | Yu et al., 2013 |
| **第一人称单数代词（I, me, my）增加** | 这是心理学界经典发现（self-focus 假说），但**本报告在本轮检索中未直接拿到 DAIC 上的量化复现数字**；Linguistic Inquiry and Word Count (LIWC) 是该方向标准工具 | 心理学经典结论（已广泛复现），DAIC 上的具体效应量本轮未核到，**不杜撰数字** | 经典 LIWC/Pennebaker 体系；建议下一路调研补证 |
| **回避行为/回答简短/内容空洞** | 与"启动延迟""话轮长度缩短"一致；Lu et al. (2023) 把话轮按 PHQ-8 类别化后，回避性回答（不直接回应症状）本身作为类别被建模 | 间接证实 | Lu et al., 2023 |

> **对项目的提示**：DAIC 已证实的可计算标记是**启动延迟、话轮长度、嗓音紧张度、填充停顿频率、凝视/微笑/自触**——这些都是多模态智能体可直接采集的信号。第一人称代词虽在心理学界成立，但在本数据集上的效应量需自行在 DAIC 复现或引用 LIWC 经典文献。

### A.4 对话式筛查 vs 固定量表（PHQ-9）：优劣

| 维度 | 对话式筛查（DAIC 式） | 固定问卷 PHQ-9 |
|---|---|---|
| 自然度/生态效度 | 高：半结构化访谈接近临床问诊，患者更易展开（Gratch et al., 2014） | 低：条目固定，作答负担重，易敷衍 |
| 伪装/社会期许偏差 | 较低：开放式回答中，行为标记（停顿、嗓音、凝视）较难刻意伪装（Scherer et al., 2013） | 较高：自评条目可刻意掩饰或夸大 |
| 标准化/可重复性 | **低**：问题顺序、追问深度、访谈者风格均变异；Yu et al. (2013) 证明行为标记的预测力随问题类型变化 | **高**：条目固定，跨研究可比 |
| 标注成本 | 高：需音频/视频转写 + 多模态标注；DAIC 仅 193 个 WoZ 访谈耗数年采集 | 极低：纸笔/线上即可 |
| 已验证性能 | DAIC-WOZ 上 F1 0.76–0.90（含 shortcut 争议） | PHQ-9 在临床样本上 sensitivity/specificity 已是金标准（≥0.85 级别，本路未展开，由临床量表那一路负责） |
| 大学生人群效度 | **未证实**：DAIC 为 LA 地区退伍军人+公众，年龄/文化/共病结构与中国大学生差异大——**外部效度是本项目必须正面回答的问题** | PHQ-9 中文版在大学生人群已有大量验证（由临床量表那一路负责） |

**结论（已证实部分）**：对话式的优势在生态效度与行为标记难伪装；劣势在标准化与标注成本。**推测/建议**：自适应对话（第二部分）正是用来弥补"标准化差"的工程手段——用 IRT 选题把开放性约束在固定条目池内，既保留自然语言，又恢复可比性。

## 第二部分　个性化/自适应提问方法（Research Line B）

### B.1 CAT-IRT 原理：简明公式

**核心思想**：不再让所有人答同一套题，而是根据每个人当前的潜能力/潜特质估计 θ，从题库里挑"此刻最能减少 θ 不确定度"的下一题，直到估计精度达标。

**1. 项目反应函数（2PL 模型，双参数 Logistic）**

受访者 i 对项目 j 作出"正确/阳性"回答的概率：

```
P_j(θ_i) = 1 / (1 + exp[ - a_j · (θ_i - b_j) ])
```

- θ_i：受访者的潜特质水平（抑郁严重度，可正可负，单位为 SD）
- b_j：项目 j 的难度/位置参数（在抑郁情境下＝该症状的阈值，b 越高代表越严重才会 endorsement）
- a_j：项目 j 的区分度参数（斜率，越大越能区分不同 θ 的人）

**2. 三参数模型（3PL，加入猜测参数 c）**：

```
P_j(θ_i) = c_j + (1 - c_j) / (1 + exp[ - a_j · (θ_i - b_j) ])
```

- c_j：猜测/低阈概率（在抑郁筛查里意义不大，一般用 2PL 或同质性 polytomous GRM）。

**3. 项目信息量（Fisher Information）**：

```
I_j(θ) = a_j² · P_j(θ) · [1 - P_j(θ)]      （2PL）
```

- 含义：在特质水平 θ 处，项目 j 能提供多少关于 θ 的信息。
- I_j(θ) 在 θ = b_j 处达到峰值——**只有当题目难度与受访者当前 θ 匹配时，这道题才最有信息量**。太简单（b ≪ θ）或太难（b ≫ θ）的题信息量都趋近 0。

**4. 总信息量与标准误**：

```
I_total(θ) = Σ_j I_j(θ)          （已施测的 k 题求和）
SE(θ̂) = 1 / √I_total(θ̂)
```

**5. 选题规则（Maximum Fisher Information, MFI）**：

```
j* = argmax_j  I_j(θ̂)      （在未施测题目中选信息量最大者）
```

**6. 更新 θ**：每答一题后，用极大后验（MAP）或 EAP 更新 θ̂：

```
θ̂ ← argmax_θ  P(已作答反应向量 | θ, a_j, b_j) · P(θ)
```

**7. 终止规则**（任一条满足即停）：
- `SE(θ̂) ≤ σ_min`（常用 0.3–0.5，相当于信度 0.91–0.75）；或
- 达到最大题数 `k ≤ k_max`；或
- 信息量增益 `< ε`。

**来源（已证实）**：Reise & Waller, *Item Response Theory and Clinical Measurement*, Annu. Rev. Clin. Psychol.；Bjorner et al., *Item banking and CAT*, Qual Life Res 2007。

### B.2 IRT/CAT 在心理健康测量中的已验证效果

| 工作 | 题库/模型 | 已验证效果 | 来源 |
|---|---|---|---|
| **PROMIS 抑郁/焦虑/愤怒题库** | 从 305 个量表 1404 个条目筛选；最终抑郁 28 项、焦虑 29 项、愤怒 29 项；校准样本 N ≈ 15,000；7 点频度量表 | 7–8 题的短版信息量即相当于传统更长量表；信息曲线在 θ ∈ [-1, +3] SD 区间优于传统量表 | Pilkonis et al., *Assessment*（PMC3153635） |

**关键已证实数字**：
- CAT 相对固定短表：**题量减半甚至更多**（Morris et al., 2017；Gibbons et al., 2016：4 题≈1 小时临床访谈）。

### B.3 自适应对话策略：分类与已验证工作

#### B.3.1 范式分类

| 范式 | 机制 | 代表工作 | 是否用于抑郁/心理健康 |
|---|---|---|---|
| **① 固定顺序问卷（无自适应）** | 所有人按 PHQ-9 顺序答 | 传统临床量表 | 金标准基线 |
| **② CAT-IRT 选题（封闭选择题）** | MFI 选题 + MAP 更新 θ | PROMIS、CAT-MH、Gibbons 2016 | 已证实高效（见 B.2） |
| **③ 自适应语言评估（开放回答 + IRT）** | 把开放文本回答 polytomize 成等级，再跑 IRT-MFI | **ALBA/ALIRT**（Varadarajan et al., NAACL 2024） | **直接针对抑郁 PHQ-9 与焦虑 GAD-7，已证实** |
| **④ RL 对话策略优化** | 把对话管理建模为 MDP，reward = 共情/诊断准确率/CBT 目标达成 | READER、PARTNER、PAL、CaiTI、Galland et al. 2025 | 心理健康咨询对话，已验证 |
| **⑤ LLM 驱动的主动/自适应追问** | LLM 根据回答充分性、症状覆盖度决定下一个追问；prompt 中注入"提问集合 + 心理诊断链 + 共情约束" | WundtGPT、EmoScan、CaiTI、InterMind | 2023–2025 新兴方向，多为小规模验证 |
| **⑥ 主动提问（proactive）vs 被动问卷** | 系统主动发起、根据用户状态调整深度 | WundtGPT 明确提出 "proactive psychologist" | 概念验证阶段 |

#### B.3.2 关键工作详情

**（1）ALBA / ALIRT —— 把 CAT 迁移到开放语言回答的关键论文**（Varadarajan, Sikström, Kjell & Schwartz, NAACL 2024 Long Papers）

这是本项目创新点最直接的学术先例。它解决的正是"IRT 要求离散作答，而开放对话是自然语言"这一矛盾。

**方法三阶段（Algorithm 1 in paper）：**
1. **Polytomization（多级化）**：对题库中每道题 j，用其回答的 LSA 词嵌入（10 维）训练 ridge regression 预测 PHQ-9/GAD-7 真分；把预测分按百分位阈值离散成 K 级（K=8 最优，K≥13 会出现缺失）。
2. **IRT 拟合**：用 EM 在离散化的反应矩阵上拟合 polytomous IRT，得到每题的特征曲线参数 (β_j, α)。
3. **自适应测试**：θ₀ = 0；循环：选下一题 `j* = argmax_j FisherInfo_j(θ̂)`；用回答 `o^j` 做 MAP 更新 θ̂。

**已验证效果（论文 Table 1 / Figure 4）：**
- **仅 3 题后 Pearson r ≈ 0.93** 对 PHQ-9；通常非自适应需至少 7 题才能达到类似水平。
- **4 题即可解释 11 题完整评估 90% 的方差（R²）**。
- 题库共 11 道开放题；前 4 题自适应施测中，11 题里只有 6 题被真正问到——即 5 题对该受访者无信息量。
- **最有信息量的首题不是症状题，而是宽泛的"Describe Yourself"和"Describe Mental Health"**；具体症状题（睡眠、食欲等）在早期自适应阶段**从不被选中**——暗示在语言评估范式下，直接问症状是冗余的。
- 另训了 Actor-Critic RL 模型（11,253 参数）与 ALIRT（88 参数）对比，**ALIRT 参数少 100 倍但性能相当甚至更优**——说明 IRT 的 Fisher Information 选题本身就已捕获了大部分价值，不需要复杂 RL。

> **对本项目的直接启示（已证实可借鉴）**：
> ① 开放回答不必直接做 IRT，先用一个轻量监督模型（ridge/BERT embedding → 预测 PHQ 分）把回答"打分分级"，再喂给 IRT；
> ② 选题规则直接复用 Maximum Fisher Information；
> ③ 首题应是宽泛自我描述题，而非 PHQ-9 第一条"你最近做事是否提不起劲"——这与临床直觉相反，但有数据支撑。

**（2）RL 对话策略在心理咨询中的工作**

### B.4 把 IRT/CAT 的"信息量选题"迁移到开放对话：技术路线图

这是本项目真正的创新空间。下表区分"已有文献证实"与"本项目建议（推测）"。

| 环节 | 已被研究证实的做法 | 本项目可采用的迁移方案（推测/建议） |
|---|---|---|
| **潜特质 θ** | PHQ-9/GAD-7 总分（ALIRT 用）；PROMIS 潜分 | 用 PHQ-9 中文版作为 θ 的 ground truth；在大学生样本上预标定 |
| **题目池** | ALIRT 用 11 道开放描述题（"Describe Yourself"等）；PROMIS 用 28 项封闭题 | 构建混合题库：① 宽泛自我描述题 2–3 道；② PHQ-9 条目改写为开放式追问（如把"最近睡眠如何"改为"能聊聊最近的睡眠情况吗"）；③ 行为观察项（停顿时长、回答长度）作为"客观题"纳入 |
| **把开放回答映射到 IRT 反应等级** | ALIRT：LSA 词嵌入 + ridge regression 预测 PHQ 分 → 百分位离散成 K=8 级 | 升级为：用 DAIC-WOZ 微调的 BERT/RoBERTa 编码回答 → 回归预测 PHQ-9 子分 → 按阈值离散；比 LSA 更强，但需标注数据 |
| **项目参数 (a_j, b_j) 标定** | IRT 用 EM 在反应矩阵上拟合（PROMIS 用 N≈15,000 标定） | **风险点**：大学生样本需 N ≥ 200–300 才能稳定标定 IRT 参数；若样本不足，先用 PROMIS/ALIRT 已发表参数做先验，再贝叶斯更新 |
| **选题规则** | Maximum Fisher Information（已证实优于固定顺序与 RL Actor-Critic，见 ALIRT 表 4） | 直接复用 MFI；额外加入"题项曝光控制"（避免每次都问同一题）与"内容覆盖约束"（必须覆盖 PHQ-9 的 9 个症状维度至少各一次） |
| **θ 更新** | MAP/EAP（ALIRT 用 MAP） | 用在线贝叶斯更新；每轮回答后实时更新 |
| **终止规则** | SE(θ̂) < 阈值 或 最大题数（PROMIS 实践） | 双终止：① SE < 0.4；② 已覆盖 ≥5 个症状维度；③ 最大 8 轮对话 |
| **多模态信号作为"客观题"** | DAIC 已证实嗓音紧张度 Acc=75%（Scherer et al., 2013）；启动延迟预测抑郁（DeVault et al., 2013） | 把音频停顿/话轮长度/嗓音紧张度编码为额外"客观反应"并入 IRT 反应向量——**这一融合方式文献中未见，属创新点** |
| **RL 是否需要** | ALIRT 证明 88 参数的 IRT 选题已超过 11,253 参数 Actor-Critic | **不要**一上来就上 RL；先做 IRT-MFI baseline，证明有效后再考虑用 RL 优化"追问深度/共情策略"这类 IRT 不擅长的维度 |
| **安全边界** | Morris et al. (2017) 指出 CAT 在低特质区间误差大 | 对 θ̂ 接近正常区间的用户，强制追加 1–2 道确认题；对 θ̂ 高风险（θ > 2 SD）直接转介，不再追求效率 |

## 第三部分　核心结论与对项目的建议

### 已被研究证实的事实
1. DAIC-WOZ 是抑郁对话检测的标准基准（193 段 WoZ 访谈，PHQ 标签），纯文本仅患者回答的可信 F1 ≈ 0.76–0.84；多模态或利用采访者 prompt 可到 0.90，但有 shortcut 争议（Burdisso et al., 2024）。
2. CAT-IRT 在心理健康测量中已被证实：平均 4 题可追踪 1 小时临床诊断访谈（Gibbons et al., 2016）；PROMIS 短版 7–8 题信息量即相当于传统长量表（Pilkonis et al.）；多维 CAT 题量减半（Morris et al., 2017）。
3. **ALIRT（Varadarajan et al., NAACL 2024）已实证**：把开放语言回答 polytomize 后跑 IRT-MFI，仅 3 题即达 Pearson r ≈ 0.93（对 PHQ-9），4 题捕获 90% 方差，而固定顺序需 7 题。**这是"自适应对话检测抑郁"已发表的最强先例。**
4. 宽泛自我描述题比具体症状题信息量更高（ALIRT Figure 4）——反直觉但有数据。
5. RL 在心理咨询对话中用于共情/策略引导已成熟（READER/PARTNER/PAL/CaiTI），但 reward 不是"最小题量下准确估计抑郁 θ"。
6. LLM 主动筛查（WundtGPT/EmoScan）2024–2025 刚起步，F1 ≈ 0.75 量级，多为概念验证。

### 推测/建议（本项目创新空间）
1. **把多模态行为信号（停顿、嗓音、话轮长度）作为 IRT 的"客观题"并入反应向量**——文献未见，是真正的创新点。
2. **用 IRT Fisher Information 增益作为 RL 的 reward 之一**，替代当前纯共情 reward——文献未见。
3. **大学生人群外部效度**必须正面解决：DAIC 是 LA 退伍军人+公众样本，需在大学生样本上重新标定 IRT 项目参数，或至少做外部验证。
4. 对标基线：文本单模态 F1 ≥ 0.78；自适应题数 ≤ PHQ-9 的一半（≤ 5 题）且与 PHQ-9 总分相关 r ≥ 0.90——这些数字有 ALIRT/PROMIS 文献支撑，是合理的工程目标。
5. **不要**用 Burdisso 式 shortcut（利用采访者 prompt）刷分；必须做"仅患者回答"的消融。
