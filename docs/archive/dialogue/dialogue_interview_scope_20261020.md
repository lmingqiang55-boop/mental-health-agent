# 测评问诊职责与表达调整（2026-10-20）

用户要求：测评模型以测评医生的问诊方式了解中小学生的情况，允许直接提问，减少机械复述；具体调节建议由独立治愈智能体承担。

## 本次改动

- 将对话角色明确为面向中小学生的 AI 心理测评访谈员，重点了解表现、持续时间、频率、程度及学习生活影响。
- 删除“先回应再追问”和“切换话题先回应”的固定顺序。普通回答无论长短，都可直接追问；确有痛苦、反问、纠正或拒绝时，再作必要回应。
- 即便上游给出“共情安慰”，也允许用贴切的问题表达关切，不强制增加一个共情气泡。
- 删除“给一个小步骤”和“五分钟做一道题”等调节建议要求与示例。测评阶段不主动安排复习、作息、运动或亲子沟通方案。
- 收尾简短提示生成结果，无需重复罗列学生的回答。安全处理及独立治愈模块保持原有职责。

修改位于 `backend/prompts/dialogue_prompt.py` 的系统提示词、本轮要求、任务尾部和视觉表达提示；同时更新既有验证脚本及检查目标。

### 第1轮

**学生：** 我14岁，读初二。最近两周作业总写得很晚，马上又要期中考试了。一坐到书桌前就紧张，越怕写不完，越容易发呆。

**系统：** 一坐到书桌前就紧张，这种感觉挺不好受的。

这种紧张的时候，身体上会有什么感觉吗，比如心跳快、手心出汗？

### 第2轮

**学生：** 有时手心会出点汗，没有胸口疼或者喘不过气。主要是怕数学又考不好。这两周一周有四五天这样，晚上做作业时最明显，跟同学玩的时候会轻松些。

**系统：** 除了做作业的时候，这两周有没有哪段时间会没来由地紧张或担心？

### 第3轮

**学生：** 没有突然就紧张的时候，基本都是想到作业和考试。晚上躺下也会想没做完的题，最近十点半上床，要翻四五十分钟才睡着，早上六点四十起床。

**系统：** 翻来覆去的那四五十分钟里，是脑子里一直在想题，还是身体不太舒服？

### 第4轮

**学生：** 主要在想题和明天的考试，身体没有不舒服。一周大概四五晚这样，睡着以后基本不醒，就是第二天早读有点困，上数学课偶尔会走神。

**系统：** 早读犯困、数学课走神，大概一周会有几天？

### 第5轮

**学生：** 一周三四天吧，数学课比较明显，别的课好一些。晚上写作业也比以前慢了，越慢就越着急。我现在该怎么办啊？

**系统：** 写作业变慢、心里着急，这种状态确实挺磨人的。

具体的调整方法，测评结束后治愈助手会陪你一起想。

这两周胃口和以前比有变化吗，比如吃不下或者吃得比平时多？

### 第6轮

**学生：** 早上紧张的时候吃得少一点，这周大概有三天，中午和晚饭都正常。没有故意少吃，也没有比以前吃得更多，体重最近没量。

**系统：** 早上吃得少的时候，是觉得没胃口，还是因为赶时间顾不上吃？

第2、3、4、6轮直接输出一个问题；第1轮和学生主动求助的第5轮仍出现了“换词复述＋泛泛评价”。6轮可见回复均未给出具体调节建议。第3轮仍重新核对了学生已提过的睡前想题，第5轮转入食欲的衔接较快。以上保留修正前的真实输出；后续针对复述问题的修正见下文。

用户指出第5轮的“写作业变慢、心里着急，这种状态确实挺磨人的”仍然机械。上一版虽然允许直接提问，但仍要求求助时“简短回应他的担心”；结合本轮上游的 `共情安慰` 动作，仍给“复述困难＋评价感受”的模板留下了空间。
