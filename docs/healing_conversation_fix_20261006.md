# 陪伴问题、双方法失败路径与检索收尾

日期：2026-10-06。本轮按用户要求修复剩余实现问题并同步规划；最终评估→记忆→治愈全链路和分龄体验验收暂不开展。

## 实现变化

- 新增 `backend/healing/conversation.py`：对明确回答的开始前困难、已经说明的序号/标题进行保守检查；换措辞追问进入一次修复。未知、否定、进一步了解不同细节及目标切换保留提问空间。
- 独立 `NarrativeCheck` 新增 `repeated_question`、`unnecessary_clarification`，核对既有对话与当前回答，禁止引用未来轮次。语义判断仍受模型可靠性限制，固定规则不覆盖任意中文表达。
- 反馈未被接受不再等于方法不明。按原句每个信号的局部指向判断是否需要澄清，重复信号分别定位，不把已明确或已成功简化的方法重新要求识别。程序追加的澄清也经过独立文字校验；已问过的相同澄清可暂停。
- 生成与修复的文字仍不合格时，原有受限降级如果也因问题被拒绝，可以去掉问题、暂停，并再次独立校验。保留合格方法、步骤、条件和待核对反馈；传输失败或最终校验失败仍返回503并回滚，不绕过安全校验。
- BM25/关键词检索在年龄、用途、执行者、场景、排除方法等原过滤之后，为人际场景明确的“意见不一致/意见不同/观点分歧”等查询追加少量同义词。只影响排序，不改知识条目、适用范围或动作。未知年龄、未知学段仍不放宽。
