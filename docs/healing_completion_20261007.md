## 已交付内容

- 从真实持久评估适配统一输入，读取年龄/年级、最近三次评估和明确可选背景；固定本轮评估绑定。
- 127 条结构化知识：103 条可用方法、8 条解释/求助、16 条继续隔离；103 条可用方法各有三种已核对表达，共 309 个。
- BM25 检索、年龄/学段/场景/执行者过滤及个人条件检查；方法只从已校验知识选择，保留步骤、成人条件和其他前提。
- 独立的支持报告和后续陪伴，最多两个活跃方法；反馈按方法关联，区分准备、尚未尝试、已尝试、拒绝及效果。
- 分龄交流、明确目标确认、成人支持按需确认、表达简化、暂停/结束、恢复/重生成、失败回滚及幂等回执；方法编号沿首次展示顺序保持。
- 风险求助、筛查当前风险刷新、生成文字的依据和单问题检查；过程审计与更新提议不进入学生视图或持久评估记录。

## 第二轮审查保留的已知边界

以下问题已用隔离状态及离线模型桩复现，本次按受控演示范围保留，未在本提交中修复。现有 725 项回归未覆盖这些组合，不能据全部回归通过宣称它们已经正常。

| 组合场景 | 当前行为与原因 |
| --- | --- |
| 高风险仅出现在治愈对话，然后主动重新生成 | 旧治愈安全证据未进入新一轮 memory，可能从 `referred/high` 恢复 `active/low` 并展示普通方法。 |
| 背景先触发中风险，治愈回答升级高风险，下一句仅回复“嗯” | 重新计算不包含上一轮治愈风险；背景中非空的较低风险覆盖 high，降回 `referred/medium`。 |
| 已有成人方法，同时反馈“第一个方法我试了，有帮助。妈妈现在不能陪我了” | 方法停用和成人条件更新正确，但新报告分支使用初次报告的反馈禁令，丢弃本句有效反馈。 |
| “我妈能陪我，但妈妈现在不能陪我”，或反向称谓 | 同一人物的称谓未归一，早先称谓的 true 使程序仍判断成人支持可用。 |
| 成人确认问题尚未回答，先暂停，回来仅回答“有” | 暂停清空待答语境，且已提问标记禁止再次询问；短答被丢弃，条件保持未知。完整明确的成人可用表述仍可另行更新。 |

前两项涉及已知风险的连续处理；若后续演示加入这些组合，应先修复再验证。其余组合也应在纳入剧本前复验。原始第二轮证据保留在本地挂载根目录 `codex_proc/healing_review_20261007_2/`，最终定向复现为 6 个失败反例、3 个通过对照（称谓问题有两个方向的反例）；失败代表上述已知问题，不能计为验收通过。

用户另行确认：回答“第一个方法我试了，没有帮助，不聊了”时立即结束，允许不记录同句反馈，维持当前行为。这项属于产品取舍，不计为缺陷。

状态仅在单进程保存，空闲 TTL 两小时、每轮最多 80 个回答。真人理解度、心理改善效果、任意自然语言表达、长期可靠性、生产负载及跨进程持久化不属于本次完成声明。
