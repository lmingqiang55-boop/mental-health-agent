# Phase 6 演示手册：多智能体运行轨迹面板

> **⚠️ 学生端面板已于本轮移除（保留后端能力）。**
> 验收后评审明确决定：学生端不再展示任何运行轨迹面板（"不需要再保留它作为学生端的
> 隐藏功能"），`AgentFlow.vue` 与 `AssessSession.vue` 里的 320px 预留列已删除。
> 后端 `AGENT_TRACE` / `/api/chat` 的 `trace` 字段**原样保留**，现在只作调试用途
> （本手册下面的开启方式、字段说明、真实日志都仍然有效），
> 但它**不产生额外模型调用，也不再出现在任何学生可见界面上**。
> `docs/archive/dialogue/phase6_trace_log.md` 仍是当时真实模型的执行记录。

> 目标：让评委一眼看出这是**多智能体动态调度**，而不是一个普通聊天机器人。
>
> 面板数据全部来自后端真实执行记录（`/api/chat` 的 `trace` 字段），
> 前端不推断、不补全。后端未开启 `AGENT_TRACE` 时 `trace` 恒为 `null`。

---

## 1. 开启方式（后端两个环境变量）

```powershell
$env:DIALOGUE_ENGINE = "graph"   # 让 LangGraph 真正调度；legacy 下拿不到图内调度信息
$env:AGENT_TRACE     = "on"      # 调试用轨迹；默认关闭
```

> `AGENT_TRACE` 接受 `1 / true / on / yes`（大小写不敏感），每轮重新读取，
> 可以现场开关而不用重启进程。

**该字段现在只供调试**：在响应 JSON 里查看，或接管理端页面，学生端不再渲染。

## 2. 三个对照场景（真实模型实测）

环境：Safety / Router / Dialogue = `deepseek-flash`，Decision = 本地 Ollama
`policy-qwen3-8b:latest`。以下是**真机跑出来的**逐轮记录，完整 `trace` JSON 见
[phase6_trace_log.md](archive/dialogue/phase6_trace_log.md)。

### 场景 A：Dialogue 自主追问 → Decision 跳过

按顺序说这 4 句：

| 轮 | 学生要说的话 |
| --- | --- |
| 1 | 最近老是睡不好，躺下要很久才能睡着 |
| 2 | 半夜还会醒一两次，早上起来特别累 |
| 3 | 白天上课就犯困，注意力也集中不了 |
| 4 | 有时候会想是不是自己太焦虑了 |

**镜头停在「第 2 轮」**，面板会显示：

```
前置安全检查（LangGraph 之外）
  ● Safety Agent                          [已调用]
    放行，进入多轮评估对话
    graph_safety_v1 · 正常/continue
图内 · LangGraph 调度
  ● Dialogue Agent                        [已调用]
    自主路由：继续当前话题（当前话题还值得追问）
    continue_topic
  ● Decision Agent                        [跳过]        ← 本轮没花决策模型
    复用当前策略 → 睡眠
  ● 视觉感知                              [已调用]
    本轮没有可用的视觉线索
    reason=missing_segment
输出
  ● 消息输出
    2 条聊天气泡
```

讲点：**Dialogue 自己判断"这个方向还能追问"，于是本轮直接跳过决策模型**，
沿用第 1 轮已经建好的全局策略「睡眠」。这就是"自主路由"。

### 场景 B：需要换话题 → Decision 真实调用

按顺序说这 4 句：

| 轮 | 学生要说的话 | 面板看点 |
| --- | --- | --- |
| 1 | 最近吃饭没什么胃口，也不太想吃东西 | 后端强制建策略（`no_active_decision`） |
| 2 | 体重好像掉了几斤 | Dialogue 自主追问，Decision 跳过 |
| 3 | 这些先不聊了吧，我们换个话题好吗 | 后端强制换策略（`topic_budget_exhausted`） |
| 4 | 我想说说和室友相处的事 | **Dialogue 请求新策略**（`user_wants_change`） |

**镜头停在「第 4 轮」**：

```
  ● Dialogue Agent                        [已调用]
    自主路由：请求新策略（学生想换话题）
    user_wants_change
  ● Decision Agent                        [已调用]
    本轮已调用决策模型 → 情绪
```

讲点：这一轮 **Dialogue 主动把控制权交回决策模型**，因为学生明确要换方向。
第 3 轮还展示了第三种情况：**后端强制换策略时会短路掉路由模型调用**，
面板如实显示「未询问 Dialogue，后端强制换策略（当前话题已问满两轮）」——
省下的一次模型调用在面板上是看得见的。

### 场景 C：视觉关怀 → 线索被采用

需要摄像头（真实采集）。按顺序说这 3 句，并在说话时保持**偏低落的表情 2~3 秒**：

| 轮 | 学生要说的话 |
| --- | --- |
| 1 | 最近做什么都提不起劲 |
| 2 | 以前喜欢打篮球，现在也不想去了 |
| 3 | 就是觉得很累，什么都不想做 |

**镜头停在「第 3 轮」**：

```
  ● Dialogue Agent                        [已调用]
    自主路由：继续当前话题（当前话题还值得追问）
  ● Decision Agent                        [跳过]
    复用当前策略 → 兴趣
  ● 视觉感知                              [已调用]
    线索有效：表情名字 · 难过 · 已说出口
    reason=mentioned
```

真实模型当轮回复（实测原样）：

> 你看起来挺难过的，这种累可能不只是身体上的。
> 那除了篮球，以前还有什么事是你愿意做的，现在也完全不想碰了吗？

讲点：**视觉线索真的进了生成过程**——"线索有效"和"已说出口"是两件事，
面板分开显示，评委能看出这不是前端写死的文案。

> ⚠️ 触发条件（如实说明）：开场前两轮不提；表情名字需要置信度 ≥0.6 且
> 多帧一致；说不出名字时退到连续效价通道。**说出口过一次之后要隔 4 轮**
> 才可能再提；如果那一轮模型没说，本轮**不计入冷却**，下一轮还会再给线索。
> 录视频前建议先完整排练一遍。

## 3. 面板的五项信息与后端字段对应

| 面板行 | 后端字段 | 说明 |
| --- | --- | --- |
| Safety Agent | `trace.safety` | `placement` 恒为 `pre_graph`，如实标注**在 LangGraph 之外**执行 |
| Dialogue Agent | `trace.dialogue` | `routed` / `need_decision` / `reason_code` / `forced_reason` |
| Decision Agent | `trace.decision` | `called` 与 `label`；未调用时显示"复用当前策略" |
| 视觉感知 | `trace.vision` | `cue_valid`（线索是否有效）与 `spoken`（是否真的说出口）分开 |
| 消息输出 | `trace.output.bubbles` | 本轮真实气泡条数 |

四种状态在界面上是**四种不同的视觉**，一眼可分：

| `state` | 徽标 | 界面表现 |
| --- | --- | --- |
| `ran` | 已调用 | 主色左边框 + 跳动的点 |
| `skipped` | 跳过 | 中性灰，说明"这一步没花模型调用" |
| `short_circuit` | 提前结束 | 警示色，安全分支提前结束 |
| `unavailable` | 不适用 | 虚线边，该引擎不提供该信息（`legacy`） |

## 4. 这个面板**没有**做什么（如实边界）

- **不新增任何模型调用**：`trace` 只是把本轮已经算好的结论搬运出来。
  开与不开，回复、气泡、轮次逐字节相同（有测试锁定）。
- **不暴露图内状态**：完整 `TurnState`、提示词、模型推理文本、API Key、
  视觉原始数值都不外传。Safety 段刻意不带 `rationale` / `evidence_quotes`。
- **不把 Safety 画进图内**：它仍是 `/api/chat` 的第一道闸门，面板单独成组，
  标题直接用后端下发的 `placement_label`：「前置安全检查（LangGraph 之外）」。
- **不做流式推送**：只做每轮一次的状态更新 + 入场动画，没有 WebSocket/SSE。
- **legacy 引擎下如实留白**：顺序执行没有图内调度，面板显示"该引擎不提供
  图内调度信息"，而不是编造一条调用链。
